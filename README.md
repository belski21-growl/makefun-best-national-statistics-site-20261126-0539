NusaStat — portal statistik nasional Indonesia yang independen: penduduk, ekonomi, harga, ketenagakerjaan, dan 38 provinsi dalam satu situs statis yang bekerja luring. Delapan halaman yang semuanya bisa dicapai lewat tautan — Beranda dengan indikator utama 2024, Ekonomi (pilih seri + jenis grafik + unduh CSV), Penduduk (tren + struktur umur + 10 provinsi terpadat), Provinsi (cari, urutkan, detail per provinsi, unduh CSV), Harga (inflasi tahunan + menurut kelompok), Ketenagakerjaan, Data & Unduhan, dan Tentang (sumber + metode). Semua angka nyata dari publikasi BPS dengan tahun acuan dan sumber tertulis; angka yang dibulatkan selalu diberi label "sekitar" / "perkiraan". Grafik SVG digambar sendiri tanpa library, tanpa build step, tanpa network saat runtime, responsif untuk desktop dan HP.

## Run it

```sh
python3 -m http.server 8000 --directory app
```

Lalu buka http://localhost:8000 di peramban.
